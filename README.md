##  Описание

Система рекомендует фильмы пользователю на основе двух подходов:

1. **Контентная фильтрация**  
   Ищет фильмы, похожие по жанрам на заданный. Используется TF-IDF и косинусное сходство.

2. **Коллаборативная фильтрация**  
   Предсказывает предпочтения пользователя на основе оценок других пользователей. Используется Alternating Least Squares из библиотеки `implicit`.

3. **Гибридный подход**  
   Объединяет рекомендации обоих методов, убирает дубликаты и возвращает топ-10 фильмов.

##  Используемые технологии

- **Python 3.9**
- **pandas, numpy** — обработка данных
- **matplotlib, seaborn** — визуализация
- **scikit-learn** — TF-IDF, косинусное сходство
- **implicit** — ALS-модель для коллаборативной фильтрации
- **scipy** — работа с разреженными матрицами
- **Jupyter Notebook** — интерактивная среда разработки
