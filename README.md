Гибридная система рекомендаций фильмов, построенная на основе контентной фильтрации по жанрам и коллаборативной фильтрации.

## Описание

Система рекомендует фильмы пользователю на основе двух подходов:

1. **Контентная фильтрация**  
   Ищет фильмы, похожие по жанрам на заданный. 

2. **Коллаборативная фильтрация**  
   Предсказывает предпочтения пользователя на основе оценок других пользователей. 

3. **Гибридный подход**  
   Объединяет рекомендации обоих методов, убирает дубликаты и возвращает топ‑N фильмов.

## Используемые технологии

- **Python 3.9**
- **pandas, numpy** — обработка данных
- **matplotlib, seaborn** — визуализация
- **scikit-learn** — TF‑IDF, косинусное сходство
- **implicit** — ALS‑модель для коллаборативной фильтрации
- **scipy** — работа с разреженными матрицами
- **Jupyter Notebook** — интерактивная среда разработки
